# RamFlow icon

`ramflow.png` is the original transparent artwork generated with the built-in image generation tool. `ramflow.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel versions of the same artwork, encoded with Pillow for Windows. The application embeds both resources, so no external image files are needed at runtime.

Generation prompt:

```text
Use case: logo-brand. Asset type: production Windows application icon for RamFlow, a resource orchestration desktop app. Create one polished original app icon, square composition, transparent outside the icon silhouette. Subject: a dark midnight navy rounded square tile with a bold continuous cyan-to-teal folded flow ribbon that subtly combines an R shape and two memory lanes; one simple recognisable symbol, strong silhouette, readable at 16 and 32 pixels. Premium restrained software design, front-on orthographic, clean softly bevelled edges, almost-flat material, subtle restrained highlight, generous safe padding about 10 percent. Use navy, cyan and teal consistent with a dark resource dashboard. No words, no letters rendered as text, no microchip pins, no diagram, no thin intricate details, no surrounding scenery, no background rectangle beyond the tile, no drop shadow outside the tile, no watermark, no collage. Deliver the icon artwork only at high resolution with actual transparent alpha.
```
