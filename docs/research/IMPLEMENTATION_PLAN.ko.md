# CARP 연구 구현 계획 — 2026-11-10

사용자가 지정한 설계를 실행한다. 목표는 KCI 정규 연구논문을 위한 검증 가능한 구현이며 게재나 성능 향상을 전제하지 않는다.

## 기준과 설계

- 기준선 `53cd18a378ce41acba3d5a97f1ec7bd2ebe13ac9`, 별도 `research/kci-baseline` 브랜치. 구현은 `research/carp`. 원래 로컬 main과 GitHub main은 수정하지 않는다.
- 기존 V1을 보존하고 동일한 `PolicyInput`을 받는 순수 판단 계층을 도입한다. 엔진은 보호 재확인 → 원래 값 저널 → 조치 → 복구를 소유한다.
- CARP는 명시적 배경 PID의 생성 신원에 연결된 최근 관측/모델만 사용한다. 이득·손실·재접근 위험·오버헤드의 정규화 추정치를 비교한다. 기본 관측 소스는 비어 있으므로 CARP는 무개입한다. 추정치를 실측 지연으로 부르지 않는다.
- 대안은 기존 엔진 전체 교체, V1 임계값만 조정, 교체 가능한 별도 정책이다. 회귀 비교와 안전 경계 보존을 위해 마지막 방식을 채택한다.
- CARP에서는 Working Set 강제 축소와 CPU Sets를 사용하지 않는다. 전경·시스템·보안·사용자 예외·활동 불명·PID 재사용 보호를 유지한다. 큐는 시작만 보류하며 실행 중 작업을 중지하지 않는다.

## 특히 확인할 실패 유형

잘못된 숫자/오래된 관측/다른 PID 생성 신원은 무개입. 전경 변경 직전 최종 재검사. 부분 적용·복구 실패 저널 보존. 관측이 사라지면 복구. 감사 기록 실패 시 새로운 연구 개입 차단, 복구는 계속. 실험 실패·중단·무효 자료 모두 보존.
