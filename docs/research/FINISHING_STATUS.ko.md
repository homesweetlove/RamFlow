# 마무리 범위와 확인 상태

2026-11-12 KST. 목표는 KCI 등재 학술지의 정규 연구논문이며 우선 대상은 TKIPS다. 게재·통계적 우위·완전성을 보장하지 않는다. 현재 완료한 실행/분석과 최종 투고 준비를 구분한다.

## 이번 확인에서 정리한 것

- 소스·안전 경계·36슬롯 원시 결과는 유지했다. 새 정책이나 성능 실험을 시작하지 않았다.
- 국내 참고문헌 R8의 게재 서지를 저자 연구실 공개 목록과 대조했다. 39(6), 380–386, Dec. 2012로 보완했다. 검색 색인에 보존된 저자 측 목록을 확인했고 직접 페이지 요청은 시간 초과였다. 저장소 PDF와 최종 게재본 본문의 동일성까지 확인한 것은 아니다. [대조 기록](PAPER_RELATED_WORK_CPU.ko.md).
- TKIPS 공식 저자 안내·윤리·범위를 다시 열람했다. 기존 미확인 사항을 임의로 해소하거나 저자 승인 사실을 만들지 않았다.

## 공통으로 적용할 완료 기준

| 항목 | 현재 상태 | 완료로 판단할 근거 |
|---|---|---|
| 실험 원본·실패·버전 | 보존 및 검증됨 | 기존 봉인과 해시를 유지하고 새 입력/버전은 별도 분리 |
| 주장과 근거 | 제한된 실증 평가 초안 작성 | 새로운 결과를 포함하면 반대/무효 결과도 반영하고 실제 비교 범위를 초과하지 않음 |
| 새로운 알고리즘의 우수성 | 아직 입증하지 못함 | 고정 조치와의 성능 차이를 결정 규칙의 차이에 귀속할 수 있는 비교가 필요 |
| 투고 형식 | 최종 편집 전 | 실제 정규논문 양식에 맞추고 표/그림/참고문헌 등을 확인 |
| 인간 저자·기여·책임 | 사실 확인 전 | 실제 저자가 기여, 원문/자료 검증, 최종 승인과 책임을 확인 |
| AI 사용 공개·사전 공개·접수 경로 | 일부 미확인 | 대상지의 적용 범위와 공개 위치를 확인하고 이력과 일치하게 기재 |

연구에서 모든 상황의 우수성이나 오류 부재를 입증할 수는 없다. 한정한 질문에 답하고, 실패와 한계 및 미확인 사항이 원고와 재현 자료에 일치하면 그 연구 범위의 작업을 종료한다. 결과가 기대와 다르다고 정책/가중치를 바꾸며 같은 검증을 끝없이 반복하지 않는다.

## 비교에서 구별할 세 가지

1. **같은 조치:** CPU 우선순위·메모리 우선순위·QoS 등 실제 OS readback 조합이 같음.
2. **같은 제한 시간:** 정한 구간에서 해당 조합이 유지된 벽시계 시간이 같거나, 사전에 정한 오차 안에서 일치함.
3. **같은 배경 손실:** 같은 무개입 기준 대비 유효 처리율 또는 완료시간 손실이 정한 예산 안에서 일치함.

2는 3을 뜻하지 않는다. 동일한 제한 시간에도 적용 시점·부하·전환 횟수·전경과의 경쟁에 따라 손실이 달라질 수 있다. 배경 손실을 맞추려면 그 손실을 별도로 측정해야 한다. 같은 전경 응답을 주장할 때도 사전에 정한 실용적 지연 허용 범위가 필요하다. 이전 대화의 ‘같은 예산’이라는 표현은 이 구분에 맞춰 해석해야 한다.

정책 보강 방향을 택하면 비교할 규칙과 위 예산 정의를 먼저 고정한다. 현재 자료로 평가 원고를 마무리하는 방향이면 이 비교가 없다는 사실을 한계로 남기고 새 알고리즘 우위를 주장하지 않는다. 두 경로 중 어느 것도 게재 보장을 뜻하지 않는다. 방향 선택 질문은 사용자에게 남겼으며 선택 전 이에 종속된 새 개입 실험을 실행하지 않았다.

## TKIPS 공식 자료 재확인

- [Aims and Scope](https://tkips.kips.or.kr/static/aim-scope): 실제 시스템 구현의 경험/실험을 다루는 응용 연구도 범위에 포함한다. 평가 논문의 범위 적합성과 개별 원고의 독창성·채택은 별개의 판단이다.
- [Instruction for Authors §1, §2.2](https://tkips.kips.or.kr/static/instruction): 온라인 제출, 심사본 저자정보 제외, 실제 저자의 기여·최종 승인·책임 등 요건을 확인했다. 인간 저자의 회원 상태나 기여·동의를 임의로 채우지 않는다.
- 같은 안내 §5.1·§5.2: 국문/영문 원고를 허용하며 국문 원고에서도 서지정보·표·그림·사사·참고문헌의 영문 작성을 안내한다. 제출 양식으로 최종 편집해야 하며 이 Markdown 초안을 그대로 양식 준수본이라고 부르지 않는다.
- [Publication Ethics](https://tkips.kips.or.kr/static/publication-ethics): 윤리 준수 별도 파일을 동반하도록 안내한다. 이를 작성했다고 실제 인간 승인까지 확인한 것으로 처리하지 않는다.

공개 페이지에서 생성형 AI 사용의 모든 허용 범위·기재 위치나 현재 코드/개발 문서 공개의 선행출판 취급을 확정하지 못했다. 부재를 허용으로 해석하지 않는다. 외부 문의·투고·결제는 수행하지 않았다. 자세한 이전 확인과 미확인은 [학술지 조사 기록](JOURNALS.ko.md)에 보존되어 있다.
